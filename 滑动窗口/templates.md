#### 最大窗口问题：求满足某条件的所有窗口中，长度最大的窗口

- 定义窗口：一般来说定义为左闭右开的窗口 `[left, right)`。
- 定义条件指标：指标用于做条件判断，它的值随着窗口的滑动而不断变化，通过对该指标去判断当前窗口是否满足条件。指标随问题的不同而不同，选择指标对算法的性能影响很大，一个好的指标既要能够正确判断窗口状态，又要能够在窗口滑动时以较低的时间空间成本进行更新。
- 窗口滑动，遵循以下固定模式：
    - 移动left直到当前窗口恰好满足条件；
    - 移动right直到当前窗口恰好不满足条件；
    - 当前满足条件的窗口为 `[left, right - 1)`，更新最大窗口；
- 上述窗口滑动时会遗漏最终的窗口，故需在退出循环后对最终窗口进行特殊处理：若此时的窗口满足条件，则更新最大窗口。

```java
public int maxWindow(int[] nums) {
    // 最大窗口问题: 滑动窗口[left, right)
    int left = 0, right = 0, n = nums.length, len = 0;
    // 定义条件指标
    "定义指标以及更新指标需要的辅助数据结构";
    // 滑动
    while(right < n) {
        // 移动left直到恰好满足条件
        while(left < right) {
            if("指标满足条件")
              	break;
            "更新指标";
            left++;
        }
        // 移动right直到恰好不满足条件
        while(right < n) {
            if("指标不满足条件")
         				break;
            "更新指标";
            right++;
        }
        // 当前满足条件的窗口为[left, right - 1)
        len = Math.max(len, right - 1 - left);
    }
    // 末尾特殊处理
    if("指标满足条件")
    		len = Math.max(len, n - left);
    return len;
}
```





#### 最小窗口问题：求满足某条件的所有窗口中，长度最小的窗口

- 定义窗口：一般来说定义为左闭右开的窗口 `[left, right)`。
- 定义条件指标：指标用于做条件判断，它的值随着窗口的滑动而不断变化，通过对该指标去判断当前窗口是否满足条件。指标随问题的不同而不同，选择指标对算法的性能影响很大，一个好的指标既要能够正确判断窗口状态，又要能够在窗口滑动时以较低的时间空间成本进行更新。
- 窗口滑动，遵循以下固定模式：
    - 移动right·直到当前窗口恰好满足条件；
    - 移动left直到当前窗口恰好不满足条件；
    - 当前满足条件的窗口为 `[left - 1, right)`，更新最大窗口；
- 由于可能不存在满足条件的窗口，故应该在最后进行一次判断。

```java
public int minWindow(int[] nums) {
    // 最小窗口问题: 滑动窗口[left, right)
    int left = 0, right = 0, n = nums.length, len = n + 1;
    // 定义条件指标: 当前窗口中的所有数字之和
    "定义指标以及更新指标需要的辅助数据结构";
    // 滑动
    while(right < n) {
        // 移动right直到恰好满足条件
        while(right < n)  {
            if("指标满足条件")
              	break;	
            "更新指标";
            right++;
        }
        // 移动left直到恰好不满足条件
        while(left < right) {
            if("指标不满足条件")
              	break;	
            "更新指标";
            left++;
        }
        // 当前满足条件的窗口为[left-1, right)
        len = Math.min(len, right - left + 1);
    }
    // 不存在满足条件的窗口
    if(len == n + 1)
      	return 0;
    return len;
}
```
